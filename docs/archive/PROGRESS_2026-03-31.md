# 温州话语料项目进度报告 2026-03-31

## 一、路线调整

### 原路线（已降级）
- Dense slot 替换流水线：8 个脚本、5 层过滤、3 次 LLM 调用
- **两轮迭代 critic pass = 0**，V1 (0/24)、V2 (0/16)
- 根本原因：LLM 不懂温州话，无法判断替换后语义是否自然；critic 同样不懂温州话，形成 blind-judging-blind 闭环
- 结论：降级为实验性支线，不再作为主产出路径

### 新路线
1. **词典例句直接提取**：从已有数据中直接获取训练句
2. **Few-shot 批量生成**：用词典例句做风格锚 + 指定必用词 → LLM 生成新句
3. **Compound 拼接**（辅助）：两条短句拼成长句，LLM 验证关系
4. 微调推迟到种子语料积累到 3,000+ 条后再启动

## 四、关键实验结论

### 4.1 Dense slot 替换（失败）
- V1: 105 raw → 93 规则通过 → 0 critic 通过
- V2: 32 raw → 16 规则通过 → 0 critic 通过
- 越收紧 gating，漏斗越窄，质量未提升

### 4.2 Compound 拼接（低产出率）
- 总输入 4,427 accepted → 已审核 ~1,200 → 111 条 pass
- Pass rate 稳定在 ~9%
- 上限估计 ~400 条（全量跑完）

### 4.3 Few-shot 批量生成（高产出率）
- DeepSeek: 100 tasks → 490 raw → **434 pass (88.6%)**
- Qwen-plus: 100 tasks → 500 raw → 72 pass (14.4%)，99% 失败原因是超长
- **DeepSeek 产出效率是 Compound 的 ~10 倍**
- 后续放量应使用 DeepSeek

## 五、待人工审查

专家需审查的文件：

1. **DeepSeek 长句 (434 条)**
   - TSV: `data/generated_long_sentences/fewshot_batch_deepseek/human_review.tsv`
   - 可直接用 Excel/Numbers 打开
   - 列：序号、温州话句子、普通话翻译、字数、场景、必用词、骨架来源词条、骨架例句、专家判定、备注

2. **Qwen 长句 (72 条)**
   - TSV: `data/generated_long_sentences/fewshot_batch_qwen/human_review.tsv`
   - 格式同上

### 审查要点
- 句子是否像温州话日常口语（而非普通话套温州话词）
- 语法结构是否自然
- 语义是否通顺、完整
- 是否适合语音训练朗读

### 审查后反馈格式
- "专家判定"列填：通过 / 不通过
- "备注"列填不通过原因（如：像普通话、语法错、用词不自然、语义不通等）
