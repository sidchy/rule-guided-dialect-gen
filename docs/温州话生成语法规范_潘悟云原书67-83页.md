# 温州话生成语法规范

基于《潘悟云-温州话音档》原书第67-83页整理，供后续温州话句子批量扩展生成使用。

## 1. 适用范围

- 本规范覆盖原书“六、语法”部分的主要内容：体貌、`有`字句、处置句、被动/使动句、双宾句、补语、否定句、反复问句、语气词。
- 页码映射已经核对：
  - 原书67-83页 = PDF 74-90页
- 原书第83页后半已进入“七、温州话同音字汇”，不纳入本规范。
- 书中部分字形在 PDF 抽取中有 OCR 噪声，本文档以“语法规则可执行”为目标做了规范化转写；如个别功能词正字后续需统一，应再结合语料正字表校对。

## 2. 生成总原则

- 优先生成温州话本身稳定的句法骨架，不要简单把普通话逐词替换成方言词。
- 凡是宾语与体标记、补语、趋向/结果成分同现时，要优先检查是否需要前置宾语。
- 区分动态持续和静态持续，不能把普通话“在/着”统一硬套成一个格式。
- 否定系统必须区分 `不 / 未 / 冇`，不能都折算成普通话“没/没有”。
- 双宾结构、结果补语结构里，直接宾语常要求“定量”，即要有数量词、指量词或其他确定量标记。
- 句末语气词承担明显语用功能，不能随机拼接。

## 3. 体貌系统

### 3.1 完成体：`爻`

- 基本格式：`V + 爻`
- 核心义：动作完成。
- 常带“消失/耗尽/变坏后的后续状态”含义。
- 适合：
  - `饭吃爻罢`
  - `菜烂爻罢`
  - `碗打破爻`
- 不适合：
  - 积极意义、无“完成/耗尽/状态变化”指向的动词一般不要随便加 `爻`
  - 例如书中明确说不能说类似“想爻三个故事”

生成约束：

- 若动词本身是动宾短语，`爻` 出现时宾语常前置。
- 可说：`舞跳爻再走`
- 不优先生成：`跳爻舞再走`

### 3.2 进行体：`著埭 + V`

- 基本格式：`著埭 + 动态动词`
- 核心义：动态过程正在持续，相当于“在 V”。
- 例式：
  - `我著埭吃饭`
  - `渠著埭洗手`
  - `外面著埭落雨`

生成约束：

- 只能搭配动态动词。
- 不要生成：
  - `著埭坐`
  - `著埭晓得`
  - `著埭快活`

变体：

- `著埭` 有弱化形式，书中记有 `da / la` 类变体。
- 做批量生成时，默认先用较稳妥的完整式 `著埭`；口语化变体可作为次级风格选项，不宜默认大量投放。

### 3.3 持续体：`V + 著埭`

- 基本格式：`V + 著埭`
- 核心义：静态状态持续，相当于“V 着”。
- 例式：
  - `门开著埭`
  - `墙上有张画挂埭`
  - `通知贴著埭罢`

生成约束：

- 只能搭配静态/结果状态动词。
- 不要生成：
  - `走著埭`
  - `笑著埭`
  - `飞著埭`

动态/静态两用动词：

- 同一动词可因位置不同而改义。
- `著埭关` = 正在关门，`关` 为动态。
- `关著埭` = 门关着，`关` 为静态状态。

### 3.4 已然体：重读 `罢` 与句末轻读 `罢`

- 重读 `罢`：表示情状已经实现，强调“实现/达到”。
- 句末轻读 `罢`：更多是把新的情况告诉对方。

搭配关系：

- `爻 + 罢`：完成已经实现
- `著埭 + 罢`：正在进行这个事实已经成立
- `V著埭 + 罢`：持续状态已经形成
- `起 + 罢`：起始状态已经发生
- `过 + 罢`：已经有过此经历

关键对立：

- `渠病起罢`：终于病了，强调实现。
- `渠病起罢` 的轻读句末式：现在病了，单纯报告新情况。

高优先生成规则：

- 若动词后无补语成分：
  - `V + 罢` 可表“已经 V 了”
  - 轻读句末 `罢` 可表“就要 V 了”
- 生成时必须按语境区分“已然”与“将然”，不能混用。

### 3.5 起始体：`起`

- 基本格式：`V + 起`
- 核心义：相当于普通话“起来”。
- 例式：
  - `天色冷起罢`
  - `渠侬打起罢`

生成约束：

- `起` 一般紧跟动词。
- 若动词中间还有宾语，宾语要前置。
- 可说：`渠歌唱起罢`
- 不宜生成：`渠唱歌起罢`

特殊规则：

- 某些动宾短语和 `起` 结合时不表起始，而表完成结果。
- 书中明确列出：
  - `画画起罢` = 画完成了
  - `字眼写起罢` = 字写好了
- 后续生成时，这类结构不要强解成“开始画/开始写”。

### 3.6 继续体：`落去`

- 基本格式：`V + 落去`
- 核心义：相当于普通话“下去”。

生成约束：

- 若前面是动宾短语，宾语前置。
- 书中明确反对：
  - `一直开会落去`
- 应改成宾语前置式：
  - `会一直开落去`

## 4. `有`字句

### 4.1 存在义 `有`

- `有 + 体词`：表示事物存在。

### 4.2 事件存在/肯定义 `有`

- `有 + VP`：表示某种动作、状态、经历的存在。
- 例式：
  - `个故事我有听过`
  - `居个事干我早早有想着`
  - `门前车站有停啊有？`

生成约束：

- `有 + VP` 不是普通话式“有在 V”，而是“存在过/确有此动作或状态”的判断。
- 适合出现在经历、先前已有打算、是否会发生某事件等语境里。

## 5. 处置句

### 5.1 基本处置标记：`逮`

- 基本格式：`逮 + 受事 + VP`
- 功能：把受事宾语提升到动词谓语之前。

核心约束：

- 受事宾语若与补语或体标记同现，往往必须前置。
- 前置有两种方式：
  - 宾语直接前置
  - 用 `逮` 做处置式前置

### 5.2 特殊复指格式：`逮渠`

- 温州话允许在动词前、助动词后用 `逮渠` 复指前置宾语。
- 同一处置句中还可以再加一层 `逮渠` 复指被处置对象。

书中给出的三种合法式：

- `身份证逮渠带身边`
- `逮身份证带身边`
- `逮身份证逮渠带身边`

### 5.3 主语前置限制

- `逮` 只能把宾语提前到动词谓语之前，不能直接提前到主语之前。
- 可说：`渠逮碗打破爻`
- 不可说：`逮碗渠打破爻`

但是：

- 用 `逮渠` 复指式，可以把宾语提前到主语之前。
- 可说：`碗渠逮渠打破爻`

## 6. 被动句和使动句

### 6.1 标记：`咐/财`（同源功能词）

- 书中把被动/使动标记写作 `咐`，与普通话“被/让”相当。
- 该词由“给”义动词虚化而来。

例式：

- 被动：`鱼咐猫儿吃爻罢`
- 被动：`衣裳咐雨淋滥爻罢`
- 使动：`财渠多休息下儿`
- 使动：`财我试试觌`

生成约束：

- 温州话里被动句和使动句形式上共用这一标记，核心是“施事/使事标记”，不是两个完全不同的句法系统。
- 因此后续生成时，不要硬把 `咐/财` 二分成两个互不兼容的标签。

重要补充：

- 书中还说明，某些句子里这个标记只是在强调后面是施事，并不一定形成严格的被动或使动意义。
- 所以后续语义判断要结合全句，不要见 `咐/财` 就机械标为被动。

## 7. 双宾句

间接宾语标记为 `财`，意思接近“给”。

### 7.1 四种基本格式

- 格式1：`V + 直接宾语 + 财 + 间接宾语`
- 格式2：`V + 财 + 间接宾语 + 直接宾语`
- 格式3：`V + 直接宾语 + 代词性间接宾语`
- 格式4：`V + 间接宾语 + 直接宾语`

### 7.2 直接宾语的“定量”约束

- 除格式1外，直接宾语通常必须是定量宾语。
- 即前面要有数量词或其他明确数量限制。

可生成：

- `送财小李一本书`
- `送一本书财小李`
- `送小李一本书`
- `送一本书渠`

不宜生成：

- `送财小李书`
- `送财小李新买的书`
- `送书渠`

### 7.3 两类双宾动词

第一类：可直接接间接宾语的转移类动词

- 如：`送、借、给、奖、卖、发、教、赔、补、退`
- 可用格式1、2、3、4

第二类：不能直接接间接宾语的动词

- 如：`留、批、写、输、介绍`
- 只能用格式1、2
- 不用格式3、4

生成时必须按动词类别选结构，不能混用。

## 8. 补语

### 8.1 `得` 后的形容词补语只能是可能补语

- 可说：
  - `讲得灵清`
  - `走得快`
- 这里不是一般程度补语，而是“能够讲清/能够走快”。

生成约束：

- `得 + 形容词` 一律按可能补语处理。
- 不要拿普通话式“说得很清楚”直接平移。

### 8.2 可能补语中的受事前置

- 带 `得` 的可能补语句，受事一般前置。
- 例式：
  - `饭吃得落就不会有病`
  - `靓样子票买得到`

### 8.3 宾语不能放在补语之后

- 温州话宾语不能出现在补语之后。
- 但宾语可以出现在结果补语之前。

可生成：

- `小刘咐汽车压一只脚脚断爻`

不宜生成：

- `小刘财汽车压脚断爻`

进一步约束：

- 结果补语前面的宾语通常也要是定量宾语。
- 不要随便用零标记、无数量的裸名词放在结果补语前。

### 8.4 零标记补语

- 某些补语不需要结构助词，可直接跟在动词后。
- 可用：
  - `你走先`
  - `我想吃添`

这类结构适合高频口语生成。

## 9. 否定句

### 9.1 `不`

- 弱读时：一般否定副词。
- 强读时：助动词，表示“不愿意”。

例：

- `居朵花不香` = 一般否定
- `我不吃` = 我不愿意吃

生成约束：

- 普通陈述否定中的 `不` 不宜随便重读化。
- 若要表达“拒绝/不肯”，才用强势的 `不`。

### 9.2 `未`

- 表示已然事件的否定，即“还没”。
- 例：`我未吃`

### 9.3 `冇` 的否定用法

- 此处应理解为 `冇`，PDF/OCR 容易误识成 `有`。
- 功能：否定 `有`字句，表示“没有发生过这种动作/行为”。
- 例：`我冇吃` = 我没有发生过吃的行为。

### 9.4 三者不可混用

- `我不吃` = 我不愿意吃
- `我未吃` = 我现在还没吃
- `我冇吃` = 我没有发生过“吃”这个行为

这是批量生成里的硬约束。

## 10. 反复问句

基本格式：

- `NP + VP + 啊 + Neg + [VP]`

其中：

- `Neg` 只能用 `不 / 未 / 冇`
- 后一个 `[VP]` 可以省略

语义分工：

- `啊不`：问事件真假
- `啊未`：问事件是否已发生
- `啊冇`：问是否存在该事件

例式：

- `画挂埭啊不？`
- `画挂埭啊未？`
- `画挂埭啊冇？`

生成约束：

- 不要把三种反复问句混成一个笼统“吗”问句。

## 11. 语气词与句末语用

### 11.1 `罢`

- 告诉对方出现了新的情况，近似普通话句末“了”。

### 11.2 `叶`

- 读 `ke/ki`，相当于“的”。
- 表所属。
- 为强调所属，可恢复本字读音 `个`。

可生成：

- `居本书是我叶`
- 强调式：`居本书是我个`

### 11.3 `暧`

- 要求对方做某事，带提醒口气。
- 例：`走暧！`

### 11.4 `唉`

- 劝诫对方做某事，并暗示不做会有不良后果。
- 例：`走唉，时间已经不早罢。`

### 11.5 `啊`

- 用于特殊疑问句、选择问句。

### 11.6 `哦/va`

- 是非问句标记，相当于普通话“吗”。

### 11.7 `吸`

- `罢 + 暧` 的合音词。
- 表示有新情况，同时提醒对方注意。
- 例：`我走吸！`

### 11.8 `啜`

- `罢 + 唉` 的合音词。
- 把新情况告诉对方，同时暗示对方应有反应。
- 例：`我走啜！`

### 11.9 `嘎`

- `叶 + 啊` 的合音词。
- 对归属、判断等做带质疑的追问。
- 例：`是你嘎？`

### 11.10 `呢`

- 表特指问、选择问，相当于普通话“呢”。
- 例：
  - `走好呢，还是嬷走好？`
  - `五马街哪能走好呢？`

生成约束：

- 句末语气词不能堆叠乱用。
- 选择问、规劝、提醒、质疑这四类语用应分别匹配：
  - 选择问优先 `啊 / 呢`
  - 提醒优先 `暧 / 吸`
  - 劝诫优先 `唉 / 啜`
  - 质疑优先 `嘎`

## 12. 批量生成硬约束清单

以下规则建议直接做成 rule gate：

- 出现 `爻` 时，优先检查是否有“完成/耗尽/变坏结果”语义。
- 动宾短语接 `爻 / 起 / 落去` 时，优先检查宾语是否需要前置。
- `著埭 + V` 只接动态动词；`V + 著埭` 只接静态结果状态。
- `得 + 形容词` 只按可能补语生成。
- 补语后不接宾语；若要保留宾语，放到结果补语前。
- 双宾格式2/3/4中的直接宾语必须尽量做成定量宾语。
- 否定必须区分：
  - `不` = 一般否定/不愿
  - `未` = 还没
  - `冇` = 没有发生过该行为
- 反复问句必须区分：
  - `啊不` = 真不真
  - `啊未` = 已没已
  - `啊冇` = 有无此事
- `咐/财` 不能简单按普通话“被/让/给”逐字替换，要按句法角色判断。

## 13. 不推荐直接生成的高风险式

- `跳爻舞`
- `著埭坐`
- `著埭晓得`
- `走著埭`
- `笑著埭`
- `飞著埭`
- `渠唱歌起罢`
- `一直开会落去`
- `逮碗渠打破爻`
- `送书渠`
- 非定量宾语直接置于结果补语前的句子
- 把 `不 / 未 / 冇` 三者混写成一个“没有”系统

## 14. 可复用句式模板

以下模板可直接用于扩句：

- `NP + O + V + 爻 + 罢`
- `NP + 著埭 + V + O`
- `NP + O + V + 著埭`
- `NP + O + V + 起 + 罢`
- `NP + O + V + 落去`
- `NP + 有 + VP`
- `NP + 逮 + O + V + 结果补语 + 爻`
- `NP + V + DO + 财 + IO`
- `NP + V + 财 + IO + DO`
- `NP + V + IO + DO`
- `NP + VP + 啊不？`
- `NP + VP + 啊未？`
- `NP + VP + 啊冇？`
- `NP + 判断句 + 嘎？`
