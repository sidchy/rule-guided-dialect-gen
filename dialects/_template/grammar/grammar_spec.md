# 你的方言语法参考文档

> 在这里放置你的方言语法参考资料。
>
> 这个文件的作用：
> 1. 作为 LLM prompt 的参考——生成和修补时会摘取相关章节
> 2. 作为人工审核的对照标准
>
> 建议结构（参考温州话版本）：

## 1. 概述

简要说明你的方言的语法特点，特别是与普通话不同的地方。

## 2. 生成总原则

在生成方言句子时需要遵守的基本原则。例如：
- 优先生成稳定的方言句式，不要逐词从普通话翻译
- 功能词的使用必须符合方言语法
- 否定系统与普通话的区别

## 3. 体貌系统（如果你的方言有）

### 3.1 完成体

描述你的方言如何表达动作的完成。

### 3.2 进行体

描述你的方言如何表达正在进行的动作。

### 3.3 持续体

描述你的方言如何表达持续状态。

## 4-N. 其他语法要点

根据你的方言特点添加章节。常见的包括：
- 处置句（相当于普通话的"把"字句）
- 被动句
- 双宾语结构
- 否定系统
- 疑问句
- 语气词

| 错误形式 | 正确形式 | 说明 |
|----------|----------|------|
| ... | ... | ... |
